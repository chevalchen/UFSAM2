# EXP-005：不确定性引导的 Support 图特征增强

状态：DECIDED / DROP（2026-11-02 复核）。当前配置未达到预设继续投入门槛；可靠性对应关系无有效增益证据。冻结方案和启动记录保留如下，正式结果见文末。

## 模型与训练

只训练新增 support 图网络及映射，完整冻结官方 COCO fold-0 adapter 与 SAM2-Large，两个 part 数据集也使用同一权重。support 最终 encoder features 用前景 masked average pool 转为最多 16×16 节点；冻结特征上 cosine 8-NN 对称图，加 self loops，D^-1/2 A D^-1/2 归一化。小图使用全部其他邻居，排序 tie 按节点索引稳定处理。

256→64 输入投影，两层 Linear(AH)→LayerNorm→GELU；64 维 mean/softplus variance heads，variance 加 1e-4。train 重参数采样、eval 使用 mean；u=mean_channel(var)，reliability=exp(-u)。节点表示乘可靠性再经零初始化 Linear 回 256 通道，散射到 16×16 网格并 bilinear 插值回 feature grid；前景内加 0.1*tanh(delta)，背景保持原值。不修改 GT mask、object pointers、query features 或 decoder 选择。

baseline=B0；uniform=G0，每张 support 内使用 reliability 均值；uncertainty=G1，逐节点可靠性；shuffled=G2，使用 G1 checkpoint 并固定打乱节点可靠性，不另训练。分割损失穿过五个冻结 memory encoder outputs、memory attention、decoder；不 detach memory。两层图聚合本身不做额外不确定性加权，隔离的唯一差别是局部 reliability gate。

G0/G1 各 seeds 0/1/2，共六 run，每 run 2400 updates，batch=1；固定 1200 train episodes 循环两次。AdamW lr=1e-4、weight_decay=1e-2、默认 betas/eps，无 scheduler、FP32、TF32 off。loss=BCEWithLogits+Dice(smooth=1)+1e-4 Gaussian KL(mean over nodes/channels)+0.1 consistency。Consistency 对原图和 10% 节点特征遮蔽视图计算 LayerNorm(mean) MSE + 0.1 log-variance MSE，两支均可微；增强与采样按 seed/step/episode/support 确定，G0/G1 匹配。每 600 steps 完整 COCO calibration，最大 aggregate class-mIoU，tie 选较早 step。

## 数据与定量比较

COCO train/calibration/held-out-base validation=1200/600/600，60 个 base 类均衡；各分区图像互斥。新 calibration/validation 排除 EXP-001/002/003/004 已观察的 validation 图像。先按稀有类保留足够 calibration/validation 图像，再固定 hash 划分与 seed=5 采样，不使用分割性能挑选。

两个 part 数据集遵循原 loader 的 val 分区内 support/query 采样及 object crop；固定到具体图像、类别和物体实例。每个 episode 六张不同原始图片。PASCAL-Part 保持 518×518，COCO/PACO 为 640×640，mask nearest；所有行相同 ImageNet normalization。PACO 根据原 COCO numeric image ID 排除新增模块 train/calibration 图像；PACO 条目都有显式 COCO ID，无需哈希替代。覆盖和排除项保存在 episodes.json 的 audit 中。part 不训练、不选 checkpoint，不宣称完整 benchmark 或像素语义从未被原 COCO adapter 见过。

报告每 seed/mean/SD 的 class-mIoU、FB-IoU、worst-decile、每类结果；part Boundary IoU 为前景边界交并，宽度 round(0.02*image diagonal)，3×3 erosion、图像外为背景，再按类别累积。G1-B0/G0/G2 先每 episode 平均三 seed FG-IoU effect，再做 10000 次 percentile bootstrap(seed=0)；CI 不是 aggregate-class-mIoU CI 或 seed CI。记录 preparation/各行 decode latency、峰值显存、reliability mean/std、修整幅度。

至少两个数据集 G1 对 B0 和 G0 同时 >=+0.5 mIoU 点且 paired CI lower>0，且任一数据集对二者均不下降超过0.2点，才支持继续投入。G1-G2 若未正向且 CI lower>0，不宣称局部可靠性对应关系有效。只有单数据集提升则报告局限性。任何非有限值、断梯度、泄漏或进程失败停止队列，不自动重试、换参、解冻或延长训练。
