### 3.2 Fixed mask refiner v1

Operator 名称：`boundary_aware_residual_logit_refiner_v1`。

固定输入：

- 1-channel selected SAM2 low-resolution query-mask logits；
- 32-channel highest-resolution SAM2 decoder feature；
- refiner 只处理 query mask，不处理 support mask。

固定网络：

1. `Conv2d(33,16,3,padding=1) + ReLU`；
2. `Conv2d(16,16,3,padding=1) + ReLU`；
3. `Conv2d(16,1,3,padding=1)`，最后一层 weight/bias 全零初始化。

固定 residual support：

\[
S(p)=\mathbf{1}\left[0.4<\sigma(M_0(p))<0.6\right],
\]

\[
M_1=M_0+S\odot R_\theta([M_0,F_{\mathrm{high}}]).
\]

`S` 从梯度图 detach。它是 fixed operator 的内在 boundary support，不是 learned spatial router，也不在 Stage A 搜索。不得改变输入、channels、hidden width、层数、kernel、概率区间、初始化或 residual 形式；任何改变均为新 Experiment ID。

### 3.7 指标、最小效应与护栏

- Primary metric：aggregate class-mIoU。
- Primary causal effect：`B1−B0`。
- Oracle headroom：各 frozen `B8−B0`。
- Paired unit：600 个 validation episode identities。
- Paired effect：同 episode 的 treatment IoU 减 B0 IoU。
- CI：paired percentile bootstrap，10000 resamples，seed 0，two-sided 95% CI。
- Minimum meaningful effect：`+0.5 mIoU point`，或 paired 95% CI 下界大于 0。
- Supporting metrics：FB-IoU、positive/negative/tied repair episode counts/rates、worst-decile episode IoU、intrinsic activated pixel area、trainable parameter count、FLOPs 和 latency。
- FB-IoU guardrail：candidate row 不得比 B0 低超过 `0.2` point。
- Worst-decile guardrail：candidate row 不得比 B0 低超过 `0.5` point。
- Sanity：B0 exact replay、600 个唯一 validation episode IDs、matched identities、checkpoint/config/manifest/provenance 均必须通过。
- Compute：一个 formal training run；一张 GPU；预估 `2–4 h` 仅作为 `DIAGNOSTIC_ONLY` 排程信息，不是 scientific evidence。
- Artifact root：`/data6/chensq/UFSAM2_runs/EXP-002/stage_a`，repository 外、不可覆盖、每个 run 独立目录。

### 3.8 Search space 与停止规则

- Bounded search space：恰好一个 fixed config；无 architecture、loss、threshold、epoch 或 dataset search。
- `PASS_TO_STAGE_B`：`B1` 或任一 frozen B8 row 满足 aggregate class-mIoU `≥+0.5` 或 paired 95% CI 下界 `>0`，且对应 guardrails、sanity 与 provenance 全部通过。通过只授权回到 Idea/Decision 阶段冻结 Stage B routing proof，不等于 `KEEP`。
- `DROP`：在 formal evidence 完整有效的前提下，B1 与所有 frozen B8 rows 的 aggregate improvement 均 `<+0.5`，且没有任何一项 paired 95% CI 下界 `>0`。停止当前 operator，不训练 router。
- `REVISE`：改变 operator inputs/topology/width/intrinsic support、loss、training exposure、data protocol、primary metric、threshold 或 stop rule；保留 EXP-002 并创建新 Experiment ID。
- `INCONCLUSIVE`：缺少 frozen input、formal implementation SHA、clean run manifest、matched rows、checkpoint/artifact/provenance，或发生 software/environment failure，导致合同不能完整裁决。
- 若 Stage A 只显示 boundary 指标改善而 mIoU 未过门槛，本合同仍不自动晋级；若要收窄为 boundary-only claim，必须新建 Experiment ID。
