## 2. 单一假设

> 在固定 SANSA、official fold-0 adapter、COCO-20i base-class 5-shot episodes 和相同 query
> decode path 的条件下，仅将一个完整 support memory 从五个 support memories 中移除，能够在
> held-out validation episodes 上产生不低于 `+0.5` class-mIoU point、且 paired 95% CI
> 下界大于 0 的 safe-oracle headroom；该结果将证明学习 query-conditioned support
> contribution selector 值得进入 Stage B。

Stage A 只回答“drop-one support-memory operator 是否有足够 headroom”。它不证明 learned
uncertainty、reliability、action-value 或最终 5-shot improvement。

## 3. 历史审计

旧 Module B 的 `--support_agg weighted_logits` 不是 memory weighting。它分别用每个 support
做 1-shot query decode，再用 expected-IoU head 分数加权 query logits，并通过 score margin
fallback 到 5-shot SANSA。

其 `HISTORICAL` COCO-20i 5-shot 四折结果为 `63.67` mean mIoU，相对 SANSA paper baseline
`64.30` 为 `−0.63`。该结果还存在以下限制：

- 没有 matched local B0、冻结 episode manifest 或 paired per-episode analysis；
- fallback margin `0.20` 由 50-episode smoke 选择；
- support score 预测单-support质量，不是其对 5-support set 的 marginal contribution；
- 融合位置在最终 logits，不是 SAM2 memory bank；
- 来自 pre-restart 混合代码，只能标记为 `HISTORICAL`。

EXP-003 不 cherry-pick 该实现，也不使用其 checkpoint、margin、temperature 或结果作为阈值。

### 4.3 Primitive counterfactual 与派生 rows

每个 validation episode 生成且只生成六个 primitive predictions：

- `B0`：五个 support memories 全部启用；
- `D0...D4`：`Dj` 删除 support slot `j`，其余四个保留。

所有其他 rows 从相同 `B0/D0...D4` masks 离线派生，不增加 decoder calls：

| Row | Selection | 证据作用 |
|---|---|---|
| `B0` | 不删除 support | Matched causal baseline |
| `B1R_s0...s4` | 用 `SHA256(episode_id, random_seed)` 在 `0..4` 均匀选择一个 slot 删除 | 五个 matched random controls |
| `B1R_mean` | 五个 random rows 的 aggregate/paired effect 均值 | Unconditional drop-one control |
| `B2S` | 删除 deterministic query-support similarity 最低的 support | Deployable non-learned control |
| `B7I` | 删除 similarity 最高的 support | Inverted negative control |
| `B8_forced` | 用 query ground truth 选择 episode IoU 最高的 `D0...D4`，即使它低于 B0 | `ORACLE` forced-action headroom |
| `B8_positive` | 用 query ground truth 选择 `max(B0,D0...D4)`；只有严格改善才删除 | `ORACLE` safe positive-gain headroom |

Ties 按最小 support slot 稳定打破。`B8_positive` 是 Stage A 的 primary treatment。

### 4.4 Frozen deterministic similarity

- Support descriptor：在 SANSA 最终 image-encoder feature map 上，将 support GT mask 以
 nearest-neighbor resize 到 feature resolution 后进行 masked average pooling。
- Query descriptor：同一 feature map 的 global average pooling，不使用 query mask、
 prediction 或 ground truth。
- Score：L2-normalized descriptor 的 cosine similarity。
- `B2S` 删除最低 score；`B7I` 删除最高 score。
- 不使用 temperature、threshold、fallback、learned projection 或 dataset-specific tuning。
- 若 descriptor dimension/interface 无法按此定义实现，返回 Idea/Decision；不得静默替换。

### 4.5 明确非目标

- 不训练 reliability、risk、expected-IoU、leave-one-out contribution 或 action-value head。
- 不连续 reweight memory，不删除两个或更多 supports，不搜索 top-k。
- 不做 per-support 1-shot query-logit fusion。
- 不加入 hflip、MTP、AV-PMC、mask post-correction、BRM、support augmentation 或 query
 pseudo-memory。
- 不使用 novel/test labels，不做 PASCAL/part-dataset claim。
- 不以 Stage A one-fold result作 `KEEP` 或最终 VERIFIED system claim。

### 4.6 指标、统计与护栏

- Primary metric：aggregate class-mIoU。
- Primary effect：`B8_positive−B0`。
- Deployable supporting effects：`B2S−B0`、`B2S−B1R_mean`。
- Paired unit：validation episode identity。
- Paired effect：同 episode treatment foreground IoU 减 B0 foreground IoU。
- CI：paired percentile bootstrap，`10000` resamples，seed `0`，two-sided 95% CI。
- Random seeds：`0,1,2,3,4`；必须报告每个 row 和 mean，不选择最佳 seed。
- Supporting metrics：FB-IoU、worst-decile episode IoU、positive/negative/tied episode
 counts、oracle intervention rate、similarity/oracle top-1 agreement、six-decode latency 和
 peak memory。
- Guardrails：B2S 的 FB-IoU 不得比 B0 低超过 `0.2` point；worst-decile episode IoU
 不得低超过 `0.5` point；B0 exact replay、600 unique identities、primitive masks
 fingerprint 和全部 provenance 必须通过。
- Compute：无训练；一张 GPU；`600 × 6 = 3600` query counterfactual decodes；目标单任务
 packet `2–6 h`，仅作 `DIAGNOSTIC_ONLY` 排程估计。

### 4.7 Search space 与停止规则

- Bounded search space：一个 frozen drop-one operator、一个 frozen similarity definition；
 无 architecture、k、temperature、threshold、epoch 或 dataset search。
- `PASS_TO_STAGE_B`：`B8_positive−B0` aggregate class-mIoU `≥+0.5`，并且 paired 95% CI
 下界 `>0`，同时 provenance、replay 和 guardrails 全部通过。两个条件必须同时满足。
- `DETERMINISTIC_CANDIDATE`：除 Stage A PASS 外，若 `B2S−B0 ≥+0.5`、paired CI 下界
 `>0` 且 guardrails 通过，可把 B2S 作为 ordinary deterministic module 候选；仍不等于
 `KEEP`。
- `DROP`：完整有效 evidence 下，`B8_positive−B0 <+0.5` 或 paired CI 下界 `≤0`；
 停止当前 drop-one operator，不训练 learned selector。
- `REVISE`：改变删除数量、连续 weighting、similarity descriptor、dataset、shots、primary
 metric、threshold 或 stop rule；保留 EXP-003 并创建新 Experiment ID。
- `INCONCLUSIVE`：缺少 exact manifest、formal SHA、clean run manifest、完整 primitive
 rows、matched identities、artifact/provenance，或 software/environment failure。
- Stage A 即使通过，也只授权回到 Idea/Decision 冻结 Stage B；不自动启动 Stage B。
