## 2. 单一假设

对于同一个 frozen post-memory feature repair operator，预测 action-specific signed gain 的 spatial/episode routing，在 matched intervention rate、activated area 与 second-decoder compute 下，能够比 random routing、entropy/current-risk routing 和 SAM2 confidence routing 更有效地提升 held-out final segmentation。

### 3.5 Stage A search space 与选择规则

- Repair topology：两个 depthwise-pointwise blocks。
- Projection width：`{32,64}`。
- Bounded residual scale：`{0.05,0.10,0.20}`。
- 每个 config：`10 epochs / 12000 optimizer steps`。
- 每个 epoch 使用同一 1200 train episodes，并在同一 600 validation episodes 上选择 best checkpoint。
- 30-step `DIAGNOSTIC_ONLY` probe 估计每 config 约 `2.6–3.0 h`，两张独立 GPU 各串行三个 configs 约 `7.8–9.0 h`；该 timing 不属于 scientific evidence。

- 通过后只冻结一个 operator；Stage B/C 不得重新选择或训练该 operator。

### 3.6 Stage B teacher、training 与 budget

- 固定 Stage A `p32_s020` operator，只验证 spatial actionability；episode action-value gate 保持关闭。
- Teacher：同一 train episode 的 `BCEWithLogits(M0,Y) - BCEWithLogits(M_all,Y)`，截断到 `[-1,1]`，以 area interpolation 下采样到 feature grid；`u*>0` 为正收益标签。
- Teacher evidence label：`ORACLE_TRAINING_TARGET`；它是 always-on repair 的 dense benefit proxy，不是单 feature-cell 的精确 causal effect。
- Loss：`SmoothL1(score,u*) + 0.25 × BCEWithLogits(score/0.25, 1[u*>0])`。
- Spatial head：`10 epochs / 12000 steps`；best checkpoint 按 validation `B2@25% area` mIoU 选择，完全相同时取更早 epoch。
- Locked area grid：`{0.10,0.25,0.50,1.00}`。
- Hard top-area：每 episode 选 `K=max(1,round(qHW))` 个 feature cells；ties 按 flattened spatial index 稳定打破。
- `q*`：只在 calibration 上选择；在 B2 calibration mIoU 距 grid 内最高值不超过 `0.2` point 的 budgets 中取最小者。
- Frozen execution packet：GPU 0 运行 `stage_b_b2_benefit_seed0`，GPU 1 运行 `stage_b_b4r_risk_seed0`；两项完成后运行 `stage_b_spatial_matched_eval_seed0`，一次性输出 validation matched rows、per-episode metrics、10000-resample bootstrap 与自动阶段建议。
- Formal execution 必须从 Stage B SHA 的 clean detached worktree 启动，不能从 branch tip 直接运行。

### 3.7 Primary metrics、护栏与裁决标准

- Stage B primary selection effect：`B2 - mean(B3 seeds)` paired episode mIoU。
- Primary specificity effect：`B2-B4R`；同时报告 `B2-B4E`。
- Bootstrap：600 个 validation episode identities；paired percentile bootstrap，`10000` resamples，seed 0，two-sided 95% CI。
- Supporting metrics：`B2-B0`、`B2-B1`、`B8S-B2`、FB-IoU、negative-repair rate、worst-decile episode IoU、actual activated area、dense positive-benefit AUPRC。
- Compute guard：每 episode 最多一个额外 decoder pass；匹配 intervention rate、activated area、second-decoder calls、trainable parameter count 与 intended comparisons 的训练暴露，并报告 FLOPs 与 latency。
- Stage C episode intervention-rate grid（仅在 Stage B 通过后适用）：`{0.25,0.50,0.75,1.00}`。
- Part track 若后续获授权，另报 Boundary IoU/F-score，并与 strict-FSS claim 分开。

`PASS_TO_STAGE_C` 必须同时满足：

- `q* < 1.0`；
- `B2-B0 >= +0.5 mIoU point` 或 paired 95% CI 下界大于 0；
- `B2-mean(B3)`、`B2-B4E`、`B2-B4R` 的 paired 95% CI 下界均大于 0；
- area/provenance/full-area sanity 全部通过；
- B2 的 FB-IoU 不比 B0 低超过 `0.2` point；
- B2 的 worst-decile episode IoU 不比 B0 低超过 `0.5` point。

`DROP_AND_STOP_EXP_001` 在以下任一条件触发：

- `q*=1.0`；
- B2 相对 B0、mean(B3)、B4E 或 B4R 任一 point effect 非正；
- 可复现的 preregistered guardrail failure。

若所有 point effects 为正但必要 CI 包含 0 且 `B2-B0 < +0.5`，记为 `INCONCLUSIVE`。若需要改变 operator、teacher、head architecture、budget grid、data protocol、primary metric 或 threshold，保留本记录并用新 Experiment ID `REVISE`。

最终 `KEEP` 还要求 B6 达到预注册主效应与 positive paired CI，在 matched budget 下优于 B3/B4/B5，guardrails/cost 可接受，并在第二个 dataset family 保持效果或明确收窄 claim；one-seed screening 不足以单独满足最终 `KEEP`。

## 5. 最终裁决与解释边界

- 最终裁决：`DROP`。
- 可支持：在当前 COCO-20i fold-0 1-shot、seed-0 screening setting 中，frozen unconditional post-memory operator 的 `B1−B0 = +0.873 mIoU`；dense oracle-proxy 仍有 headroom。
- 不可支持：learned action-specific spatial selection 优于 random、entropy 或 generic current-risk；完整 episode-level AV-PMC routing；最终多-seed/cross-dataset `KEEP` claim。
- `B8S−B2 = +1.617` 与 AUPRC `0.7278` 仅说明 oracle-proxy headroom/排序信号存在，不证明 learned B2 能将其转化为更好的 segmentation。
- 不得 post-hoc 改用 `q=0.25`、重选 checkpoint、改变 teacher/head/loss，或直接启动 Stage C 挽救 EXP-001。
- 若未来保留 unconditional operator，或修改 operator、teacher、head、routing、threshold、metric 或 data protocol，必须回到 Idea/Decision 阶段并创建新的 Experiment ID。
- 为满足 portfolio 主干目标，默认转向下一候选模块，不追加 EXP-001 非预注册 ablation。
